## 완료된 작업: 한미그룹 채용 React 변환

- 원본 정적 사이트: `.vscode/한미그룹채용_리액트버전/`
- 독립 Vite + React(JavaScript) 프로젝트: `한미그룹채용_리액트/`
- 원본 채용 페이지를 11개 섹션과 공통 요소의 React 컴포넌트로 나눠 `src/components/`에 구성했습니다.
- 원본 이미지, JSON, CSS, 인터랙션 스크립트, Canvas 시선 추적 자산을 `public/`에 보존했습니다. 별도 읽기 추적 Canvas 자산도 복사했습니다.
- React 마운트 후 Canvas 메타데이터, Canvas 플레이어, 기존 사이트 인터랙션 스크립트를 순차 로드하도록 연결했습니다. 스크립트 로드 실패는 화면에 오류로 표시합니다.
- Node.js LTS 26.13.0을 설치했습니다.
- `vite.config.js`의 `base`를 `"./"`로 설정하고, 앱 스크립트 URL과 헤더 홈 링크도 상대 경로로 바꿨습니다.
- `dist/index.html`에서 `./CSS/main.css` 및 `./assets/...` 경로를 확인했고, 주요 CSS·이미지·JSON·Canvas 파일이 `dist/`에 포함되는 것도 확인했습니다.
- 마지막 상대 경로 기준 `npm run build`가 성공했습니다.
- 개발 서버를 `http://127.0.0.1:5173/`에서 실행하고 외부 브라우저로 열었습니다. 서버는 마지막 확인 시 실행 중이었으나, 후속 작업 전 필요하면 상태를 확인합니다.
- 린트는 통과했습니다. 원본 `public/js/main.js`에서 미사용 변수 1건과 표현식 경고 2건이 보고됐으며, 이번 작업에서는 수정하지 않았습니다.
- 사용자가 테스트를 그만하라고 요청했습니다. 이후 별도로 요청하지 않는 한 브라우저 테스트나 추가 검증을 실행하지 않습니다.

## 프로젝트에서 자주 볼 위치

- `한미그룹채용_리액트/src/App.jsx`: React 페이지 조립과 기존 스크립트 로드
- `한미그룹채용_리액트/src/components/`: 페이지 섹션별 React 컴포넌트
- `한미그룹채용_리액트/public/`: 원본 CSS, 이미지, JSON, 스크립트, Canvas 자산
- `한미그룹채용_리액트/vite.config.js`: 상대 경로 배포 설정
- `한미그룹채용_리액트/dist/`: 마지막 성공 빌드 산출물

## 개발 및 빌드 명령

프로젝트 폴더에서 `npm run dev`로 개발 서버를 실행하고, `npm run build`로 배포 파일을 생성합니다. 배포 산출물은 `dist/`입니다.
